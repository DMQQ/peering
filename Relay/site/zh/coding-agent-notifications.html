Claude Code 需要你时，在 iPhone 上收到通知

启动智能体，放心走开，只在它真正需要你时再回来。

简而言之。Peering 会监视你 Mac 上的 Shell。当其中一个停下来向你询问什么时 （编程智能体的权限请求、sudo 密码、一个是或否的问题），你的 iPhone 会显示一条带有该问题的横幅。 轻点它，就进入那个 Shell，随时可以回答。

放任智能体独自运行的问题

Claude Code、Codex 等工具在你不在身边时发挥得最好。然后它们会停下来询问是否可以运行某条命令，并等待。 没有任何东西提醒你。一个小时后你回来，才发现它在你离开两分钟后就问了，此后一直在等你回答。

已经完成的构建、等待输入密钥口令的 git push，或是要求你确认的迁移，也是同样的情形。 机器已经在等你了，只是你不知道。

Peering 如何解决

Mac 应用会读取你的 Shell 输出，并识别两类问题：密码提示和是或否的确认。一旦出现， Mac 就会通过 Peering 的中继向你的 iPhone 发送通知，并引用该提示的内容， 让你分得清是哪个智能体在询问、问的是什么。

  • 它同时适用于终端和 iTerm窗口以及 Peering 自己的 Shell，所以你不必改变启动智能体的方式。
  • 即使App 已关闭、手机已锁定，它也会像其他通知一样送达。
  • 每个提示只提醒一次，并在你回答后重新待命，所以一个一直没人回答的问题不会每隔几秒就震动一次。
  • 在 Peering 自己的 Shell 中，当一条耗时五秒或更久的命令结束时，它也会通知你。

在手机上回答

轻点横幅，Peering 会带你进入发出提问的 Shell 或窗口。它自己的 Shell 会全屏打开，并带有为手机设计的按键行： Escape、Control、Tab、方向键，以及逐词移动。输入 y，从密码管理器粘贴密码， 或者先看一看智能体想要应用的差异。如果你更想看整个桌面，可以在同一个 App 里切换到 Mac 的屏幕。

设计上就注重隐私

承载会话的中继无法读取会话：你的 iPhone 和 Mac 各自持有自己的密钥，会话的任何内容都不会存储在服务器上。 无需创建账户。中继能看到什么、不能看到什么，隐私政策中有明确说明。

费用

终端、连接服务器的 SSH 和文件浏览器在所有套餐中都免费。Shell 在等待时收到通知属于 Relay 套餐， 每月 $1.99 或每年 $14.99，它同时也取消了从其他网络连接你的 Mac 时每天一小时的限制。

常见问题

Peering 能识别哪些提示？

密码提示（包括 sudo 和 SSH 密钥口令），以及是或否的确认，编程智能体的权限请求正是这种形式。在 Peering 自己的 Shell 中，当一条运行了五秒或更久的命令结束时，它也会通知你。

它在终端和 iTerm 中也能用吗，还是只能用于 Peering 自己的 Shell？

两者都可以。Peering 会监视 Mac 上的终端和 iTerm 窗口，也会监视它自己打开的 Shell。

iPhone 上的 App 需要保持打开吗？

不需要。Mac 通过中继发送横幅通知，所以即使 App 已关闭、手机已锁定，通知也会送达。

它包含在哪个套餐中？

终端本身在所有套餐中都免费。Shell 在等待时收到通知需要 Relay 套餐，每月 $1.99 起，或每年 $14.99。
