Ajouter ce Mac

Vous avez scanné le code Peering d'un Mac.

Sur un iPhone où Peering est installé, ce lien ouvre l'app et lance l'association avec le Mac qui l'a affiché. Vous voyez cette page parce que l'app n'est pas encore installée sur cet appareil, ou parce que le lien a été ouvert ailleurs.

  1. Installez Peering pour iPhone.
  2. Scannez de nouveau le code sur le Mac, avec l'Appareil photo ou depuis l'app.
  3. Comparez les six chiffres affichés par les deux écrans, et confirmez.
