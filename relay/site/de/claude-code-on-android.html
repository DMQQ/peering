Claude Code auf Android, ausgeführt auf deinem Mac

Geschrieben von den Leuten, die Peering bauen. Im November 2026 mit dem Code der App abgeglichen.

Kurz gesagt. Dein Coding-Agent läuft weiter auf deinem Mac, mit deinen Repositorys, Schlüsseln und Werkzeugen. Peering auf Android holt seinen Chat aufs Handy: einen starten, mitlesen, seine Fragen beantworten, prüfen, was er geändert hat, und in der Benachrichtigung auf „Erlauben“ oder „Ablehnen“ tippen, wenn er einen Befehl ausführen will.

Warum der Agent auf dem Mac läuft und nicht auf dem Handy

Claude Code, Codex und OpenCode brauchen einen echten Rechner: den Checkout, die Build-Tools, die Testsuite, deine Git-Zugangsdaten. Einen davon in einer Terminal-App auf dem Handy laufen zu lassen, heißt, all das woandershin zu kopieren. Peering lässt die Arbeit, wo sie schon ist, und macht das Handy zur Fernbedienung dafür. Legst du das Handy weg, arbeitet der Agent weiter.

Was du vom Handy aus tun kannst

  • Einen Agenten mit einem Tipp starten, in jedem Ordner auf dem Mac. Unterstützt werden Claude Code, Codex und OpenCode.
  • Ihm als Chat folgen, nicht als durchlaufendes Terminal: Nachrichten, Tool-Aufrufe, Sub-Agenten und die Dateien, die er angefasst hat, mit Tabs, wenn mehrere Chats gleichzeitig laufen.
  • Seine Fragen beantworten. Fragt ein Agent etwas mit mehreren Antwortmöglichkeiten, tippst du eine an. Fragen mit mehreren Teilen beantwortest du nacheinander.
  • Einen Befehl erlauben oder ablehnen, direkt in der Benachrichtigung, ohne die App zu öffnen.
  • Die Änderungen prüfen: Ein Eingang „Zu prüfen“ sammelt Chats mit fertiger Arbeit, und jeder zeigt den Diff pro Datei. Nach einer Runde, die Dateien geändert hat, erscheinen Knöpfe für den nächsten Schritt.
  • Mit Vorschlägen tippen: Slash-Befehle und @-Erwähnungen von Dateien werden beim Tippen vorgeschlagen, und du kannst einen Prompt auch diktieren.
  • Ins Terminal oder auf den Bildschirm wechseln, wenn der Chat nicht reicht. Die Shell des Agenten, ein normales Terminal und der ganze Schreibtisch des Macs sind in derselben App.

Freigaben aus der Benachrichtigungsleiste

Will Claude Code etwas ausführen, das du nicht erlaubt hast, hält es an und wartet. Auf Android zeigt Peering eine Benachrichtigung mit dem Agenten und dem Befehl, dazu die Knöpfe „Erlauben“ und „Ablehnen“. Antworte aus der Benachrichtigungsleiste oder vom Sperrbildschirm. Dasselbe passiert, wenn ein Agent eine Runde beendet oder ein Terminal auf dem Mac auf ein Passwort wartet.

Genau genommen funktioniert das so: Android-Benachrichtigungen kommen an, während Peering im Hintergrund eine Sitzung offen hält. Eine dauerhafte Benachrichtigung nennt den Mac und hat einen Knopf zum Trennen, und der Mac pausiert das Bild, damit nichts gestreamt wird, was du nicht siehst. Das kannst du in den Einstellungen abschalten. Beendet Android die App selbst, etwa durch strenge Akku-Einschränkungen, bleiben die Hinweise aus, bis du sie wieder öffnest. Die iPhone-App bekommt sie auch bei geschlossener App, siehe Benachrichtigungen für Coding-Agenten.

Einrichten

Installiere Peering für Mac und den Agenten, den du nutzt, wie gewohnt. Installiere Peering auf dem Handy aus Google Play, sobald es dort gelistet ist, koppele einmal mit dem sechsstelligen Code und öffne den Tab „Agenten“. Peering findet die Agenten, die auf dem Mac installiert sind. Es liefert selbst keinen mit und bezahlt keinen, und es sieht nie deine API-Schlüssel oder dein Abo.

Sicher genug, um es laufen zu lassen

Alles zwischen Handy und Mac ist Ende-zu-Ende-verschlüsselt, auch der Chat und die Freigaben. Das Relay, das die Verbindung unterwegs trägt, kann nichts davon lesen. Die Android-App lässt sich mit Fingerabdruck oder Gesicht sperren, damit ein geliehenes Handy keinen Befehl freigeben kann.

Was es kostet

Agenten, Terminal und Hinweise gibt es in jedem Tarif. Kostenlos im eigenen Netzwerk ohne Zeitlimit, dazu 30 Minuten Relay-Zeit pro Tag, um den Computer aus einem anderen Netzwerk zu erreichen. Pro (2,99 $ im Monat) oder Lifetime (einmalig 24,99 $) hebt das Tageslimit auf. Das sind die US-Preise, Google Play zeigt dir deine in Landeswährung.

Fragen

Kann ich Claude Code auf Android nutzen?

Claude Code läuft auf einem Computer, nicht auf einem Handy. Mit Peering läuft es weiter auf deinem Mac, und die Android-App zeigt seinen Chat, startet neue, beantwortet seine Fragen und gibt Befehle frei.

Funktioniert es auch mit Codex und OpenCode?

Ja. Peerings Agenten-Ansicht unterstützt Claude Code, Codex und OpenCode, wenn sie auf dem Mac installiert sind.

Kann ich einen Befehl freigeben, ohne die App zu öffnen?

Ja. Die Benachrichtigung hat die Knöpfe „Erlauben“ und „Ablehnen“. Auf Android kommt sie an, während Peering im Hintergrund eine Sitzung offen hält.

Sieht Peering meinen Code oder meine API-Schlüssel?

Nein. Der Agent läuft auf deinem Mac mit deinen eigenen Zugangsdaten, und die Verbindung zwischen Handy und Mac ist Ende-zu-Ende-verschlüsselt.

Gibt es eine Windows-Version?

Der Windows-Host ist in einer frühen Beta. Er hat den Chat für Claude Code, aber noch keine Änderungsprüfung, kein Commit und kein Push, und er lief noch nie auf einem echten PC.
