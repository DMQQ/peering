Add this Mac

You scanned a Mac's Peering code.

On an iPhone with Peering installed, this link opens the app and starts pairing with the Mac that showed it. You are seeing this page because the app is not installed on this device yet, or the link was opened somewhere else.

  1. Install Peering for iPhone.
  2. Scan the code on the Mac again, with the Camera or from inside the app.
  3. Compare the six digits both screens show, and confirm.
