简而言之。屏幕共享内置于 macOS，足以查看和控制另一台 Mac。Apple Remote Desktop 在此基础上增加了同时管理多台 Mac 的能力。两者都没有 iPhone 或 iPad 应用，也都不提供从网络外部连进来的通道。

屏幕共享

在“系统设置”的“通用”>“共享”中打开它。在另一台 Mac 上，通过访达或“屏幕共享”应用按名称或地址连接。 它在局域网中速度很快，而且不用花钱。

Apple Remote Desktop

ARD 在目标 Mac 上使用同一个共享服务，并加上管理员这一侧的功能：电脑列表、一次向多台复制文件、发送 Unix 命令、 关于已安装软件和硬件的报告。如果你负责一间机房或一个办公室的 Mac，它物有所值。对于只有一台 Mac 的个人，它比屏幕共享多不了什么。

常见问题

Apple Remote Desktop 和屏幕共享有什么区别？

屏幕共享内置于 macOS，让你从一台 Mac 查看并控制另一台 Mac。Apple Remote Desktop 是单独的付费管理员应用，提供同时管理多台 Mac 的工具，例如发送文件、运行命令和收集报告。

能从 iPhone 使用屏幕共享吗？

用 Apple 的软件不行。iOS 上没有屏幕共享客户端。需要第三方应用，例如 Peering、Screens 或 Jump Desktop。

屏幕共享能在家庭网络之外使用吗？

只有在你自己提供连接通道时才行，例如通过 VPN。它不会自己建立这条通道。
