Управление ПК с Windows с телефона: ранняя бета

Написано создателями Peering, ноябрь 2026. Сначала прочтите блок ниже.

Прямо говоря: Peering Host для Windows собран и проходит тесты, но ещё не запускался на настоящем ПК с Windows. На странице загрузки его нет. Если хотите попробовать раньше и рассказать нам, что ломается, напишите на support@getpeering.app. Если вам нужно что-то, что работает на Windows уже сегодня, страницы о Chrome Remote Desktop и TeamViewer подскажут, чем воспользоваться.

Что такое хост для Windows

Те же приложения Peering для телефона, которые управляют Mac, могут связаться с ПК на Windows, где запущен Peering Host. Он живёт в области уведомлений, показывает в своём окне шестизначный код связывания, принимает связанные телефоны в вашей сети и через релей и хранит ключ каждого устройства под защитой Windows. В списке на телефоне ПК отмечен как «Бета».

Что уже сделано

  • Картинка: один дисплей или одно окно как H.264 с аппаратным кодированием при 15, 30 или 60 кадрах в секунду, с нарисованным указателем.
  • Ввод: мышь, клавиатура и текст, включая режим трекпада и жесты несколькими пальцами с телефона.
  • Звук с ПК и общий буфер обмена.
  • Терминалы: оболочки на ПК в приложении на телефоне.
  • Чат с Claude Code, с подтверждениями и законченными ходами на телефоне.
  • Файлы: просмотр папок ПК и загрузка файлов, папок в виде zip.
  • Доступ: то же зашифрованное связывание, обнаружение в локальной сети и релей, что и у Mac.

Чего пока нет

  • Источников-приложений, миниатюр и мозаики окон.
  • Виртуальных рабочих столов, виртуальных дисплеев и шторки приватности.
  • Удержания ПК в активном состоянии и расписаний пробуждения.
  • Проверки изменений агента, commit и push с телефона.
  • Цифровой подписи кода. Windows SmartScreen предупреждает при первом запуске хоста, потому что издатель ещё не проверен.

Кому стоит попробовать сейчас

Тем, кто спокойно относится к бете: может запустить неподписанный установщик, прочитать файл журнала, когда что-то не появляется, и прислать нам то, что видит. Установщик ставит программу для текущего пользователя, не требует прав администратора и может запускать хост при входе в систему. Исходный код лежит в репозитории, если вы предпочитаете собрать его сами.

Со стороны телефона

Используйте приложение для Android (скоро в Google Play) или приложение для iPhone. Android скрывает элементы управления, которые хост для Windows не поддерживает. Приложение для iPhone пока показывает некоторые элементы только для Mac, которые хост для Windows игнорирует.

Цены

Те же, что для Mac: бесплатно в вашей сети, 30 минут релея в день из других сетей, и Pro или «Навсегда» без ограничений. Тариф привязан к телефону, поэтому распространяется на все компьютеры, с которыми вы связались.

Вопросы

Можно ли управлять ПК с Windows с телефона через Peering?

В ранней бете. Хост для Windows собран и проверен тестами, но ещё не запускался на настоящем ПК. Ранний доступ можно запросить на support@getpeering.app.

С каких телефонов можно управлять хостом для Windows?

С приложений Peering для Android, которое скоро появится в Google Play, и для iPhone и iPad.

Почему Windows предупреждает меня при запуске?

Установщик беты пока не подписан, поэтому SmartScreen не узнаёт издателя. Если вы доверяете источнику, выберите «Подробнее», а затем «Выполнить в любом случае».

Нужны ли хосту для Windows права администратора?

Нет. Установщик ставит программу только для текущего пользователя.

Можно ли запускать Claude Code с телефона?

Да, в хосте для Windows есть чат с Claude Code с подтверждениями на телефоне, но пока нет проверки изменений, commit и push.
