휴대폰으로 Windows PC 제어하기: 초기 베타

Peering을 만드는 사람들이 썼습니다, 2026년 11월. 무엇보다 먼저 아래 상자를 읽어 주세요.

솔직히 말하면: Windows용 Peering Host는 만들어졌고 테스트도 통과하지만, 아직 실제 Windows PC에서 실행된 적이 없습니다. 다운로드 페이지에도 없습니다. 미리 써 보고 무엇이 깨지는지 알려 주실 분은 support@getpeering.app로 연락해 주세요. 지금 Windows에서 동작하는 것이 필요하다면 크롬 원격 데스크톱과 팀뷰어 페이지에서 대신 쓸 것을 안내합니다.

Windows 호스트란

Mac을 제어하는 같은 Peering 휴대폰 앱이 Peering Host를 실행하는 Windows PC와도 페어링할 수 있습니다. 호스트는 트레이에 머물며, 창에 여섯 자리 페어링 코드를 보여 주고, 내 네트워크와 릴레이를 통해 페어링된 휴대폰을 받아들이며, 각 기기의 키를 Windows의 보호 기능으로 지킵니다. 휴대폰 목록에는 PC가 베타로 표시됩니다.

만들어진 것

  • 화면: 디스플레이 하나 또는 윈도우 하나를, 하드웨어 인코딩 H.264로 초당 15, 30, 60프레임, 포인터를 그려 넣어 전송.
  • 입력: 마우스, 키보드, 텍스트. 휴대폰의 트랙패드 모드와 여러 손가락 제스처 포함.
  • 소리: PC의 소리, 그리고 공유 클립보드.
  • 터미널: 휴대폰 앱에서 PC의 셸.
  • Claude Code 채팅: 승인 요청과 완료된 턴을 휴대폰으로 전송.
  • 파일: PC의 폴더를 탐색하고 파일을, 폴더는 zip으로 다운로드.
  • 연결: Mac과 같은 암호화 페어링, LAN 검색, 릴레이.

아직 없는 것

  • 앱 단위 공유, 미리보기 이미지, 윈도우 모자이크.
  • 가상 데스크톱, 가상 디스플레이, 프라이버시 커튼.
  • PC를 깨어 있게 유지하기와 깨우기 일정.
  • 휴대폰에서 에이전트 변경 검토, 커밋, 푸시.
  • 코드 서명. 게시자가 아직 확인되지 않아, 호스트를 처음 실행하면 Windows SmartScreen이 경고합니다.

지금 써 볼 만한 사람

베타에 익숙한 분. 서명되지 않은 설치 프로그램을 실행하고, 무언가 나타나지 않을 때 로그 파일을 읽고, 본 것을 알려 줄 수 있는 분입니다. 설치 프로그램은 사용자별이라 관리자 권한이 필요 없고, 로그인할 때 호스트를 시작하게 할 수 있습니다. 직접 빌드하고 싶다면 소스가 저장소에 있습니다.

휴대폰 쪽

안드로이드 앱(Google Play 출시 예정)이나 iPhone 앱을 쓰세요. 안드로이드는 Windows 호스트가 지원하지 않는 컨트롤을 숨깁니다. iPhone 앱은 현재 Windows 호스트가 무시하는 일부 Mac 전용 컨트롤을 보여 줍니다.

가격

Mac과 같습니다. 내 네트워크에서는 무료, 다른 네트워크에서는 하루 30분의 릴레이 시간, 무제한은 Pro나 평생. 요금제는 휴대폰에 속하므로 페어링한 모든 컴퓨터에 적용됩니다.

자주 묻는 질문

Peering으로 휴대폰에서 Windows PC를 제어할 수 있나요?

초기 베타로 가능합니다. Windows 호스트는 만들어지고 코드 상으로 테스트되었지만 아직 실제 PC에서 실행된 적이 없습니다. 얼리 액세스는 support@getpeering.app로 요청하세요.

어떤 휴대폰으로 Windows 호스트를 제어하나요?

Google Play 출시 예정인 안드로이드용 Peering 앱과 iPhone, iPad용 앱입니다.

실행하면 Windows가 왜 경고하나요?

베타 설치 프로그램이 아직 코드 서명되지 않아 SmartScreen이 게시자를 알아보지 못합니다. 출처를 신뢰한다면 추가 정보를 누른 뒤 실행을 선택하세요.

Windows 호스트에 관리자 권한이 필요한가요?

아니요. 설치 프로그램은 현재 사용자에게만 설치합니다.

휴대폰에서 Claude Code를 실행할 수 있나요?

네. Windows 호스트에는 휴대폰에서 승인하는 Claude Code 채팅이 있지만, 변경 검토, 커밋, 푸시는 아직 없습니다.
