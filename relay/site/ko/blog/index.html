Peering은 어떻게 작동하나요

계정 없는 원격 데스크톱의 바탕이 되는 연결, 화면, 입력, 신뢰에 대한 엔지니어링 노트입니다.

  • 6분 읽기

    iPhone은 어떻게 어디서나 Mac에 닿을까

    같은 Wi-Fi에서 Mac을 찾는 방법, 인터넷 너머로 릴레이가 둘을 소개하는 방법, 화면이 직접 오가는 방법.

  • 7분 읽기

    Peering은 Mac 화면을 iPhone으로 어떻게 스트리밍할까

    캡처, 하드웨어 인코딩, 데이터그램, 손실 복구: Mac 화면의 한 프레임이 iPhone에 닿기까지.

  • 6분 읽기

    계정 없는 페어링: Peering이 신뢰할 대상을 정하는 방법

    Peering에는 로그인이 없습니다. 양쪽 화면의 여섯 자리 코드가 중간자가 없음을 증명합니다.

  • 6분 읽기

    iPhone의 탭은 어떻게 Mac의 클릭이 될까

    정규화된 좌표, 합쳐지는 마우스 이동, macOS 키 코드, 유니코드 텍스트: 손가락에서 Mac까지 입력의 경로.

  • 6분 읽기

    Peering 릴레이가 볼 수 있는 것과 볼 수 없는 것

    릴레이 서버가 아는 것(주소, 기기 ID, 사용량)과 알 수 없게 만든 것(화면, 키 입력, 클립보드).
