안드로이드에서 Claude Code를, Mac에서 실행하며

Peering을 만드는 사람들이 썼습니다. 2026년 11월, 앱의 실제 코드와 대조해 확인했습니다.

요약하면. 코딩 에이전트는 내 저장소, 키, 도구가 있는 Mac에서 계속 실행됩니다. 안드로이드용 Peering은 그 채팅을 휴대폰으로 가져옵니다. 새로 시작하고, 지켜보고, 질문에 답하고, 바뀐 내용을 검토하고, 명령 실행을 요청하면 알림에서 허용이나 거부를 탭하세요.

왜 휴대폰이 아니라 Mac에서 에이전트를 돌리나

Claude Code, Codex, OpenCode에는 진짜 컴퓨터가 필요합니다. 체크아웃한 코드, 빌드 도구, 테스트, git 자격 증명. 휴대폰 터미널 앱에서 돌리려면 그 모든 것을 다른 곳으로 옮겨야 합니다. Peering은 작업을 원래 있던 곳에 두고 휴대폰을 리모컨으로 만듭니다. 휴대폰을 닫아도 에이전트는 계속 일합니다.

휴대폰으로 할 수 있는 일

  • 탭 한 번으로 에이전트 시작: Mac의 어느 폴더에서든. Claude Code, Codex, OpenCode를 지원합니다.
  • 채팅으로 지켜보기: 스크롤되는 터미널이 아니라 메시지, 도구 호출, 하위 에이전트, 건드린 파일로. 여러 채팅이 동시에 돌면 탭으로 나뉩니다.
  • 질문에 답하기. 에이전트가 선택지가 있는 질문을 하면 하나를 탭하세요. 여러 부분으로 된 질문은 하나씩 답합니다.
  • 명령 허용 또는 거부: 앱을 열지 않고 알림에서.
  • 변경 사항 검토: 검토 대기 받은편지함에 작업이 끝난 채팅이 모이고, 각각 파일별 diff를 보여 줍니다. 파일을 바꾼 턴이 끝나면 후속 버튼이 나타납니다.
  • 힌트와 함께 입력: 입력하는 동안 슬래시 명령과 파일 @멘션이 제안되고, 프롬프트를 받아쓰기로 말할 수도 있습니다.
  • 터미널이나 화면으로 내려가기: 채팅만으로 부족할 때. 에이전트의 셸, 일반 터미널, Mac 데스크톱 전체가 모두 같은 앱에 있습니다.

알림창에서 승인하기

Claude Code가 허용하지 않은 무언가를 실행하려 하면 멈추고 기다립니다. 안드로이드에서는 Peering이 에이전트와 명령을 알려 주는 알림을 허용, 거부 버튼과 함께 띄웁니다. 알림창이나 잠금 화면에서 바로 답하세요. 에이전트가 턴을 마쳤을 때나 Mac의 터미널이 비밀번호를 기다릴 때도 마찬가지입니다.

언제 동작하는지 정확히 말하면, 안드로이드 알림은 Peering이 백그라운드에서 세션을 열어 두는 동안 도착합니다. 진행 중 알림에 Mac 이름과 연결 끊기 버튼이 표시되고, Mac은 보이지 않는 화면을 보내지 않도록 영상을 멈춥니다. 설정에서 끌 수 있습니다. 공격적인 배터리 제한 등으로 안드로이드가 앱을 종료하면 다시 열 때까지 알림이 오지 않습니다. iPhone 앱은 앱을 닫아도 알림을 받습니다. 코딩 에이전트 알림을 참고하세요.

설정 방법

Mac용 Peering과 사용하는 에이전트를 평소처럼 설치하세요. Google Play에 등록되면 휴대폰에 Peering을 설치하고, 여섯 자리 코드로 한 번 페어링한 뒤 에이전트 탭을 여세요. Peering은 Mac에 설치된 에이전트를 찾아냅니다. 에이전트를 포함하거나 비용을 대신 내지 않으며, API 키나 구독 정보를 보지 않습니다.

켜 두어도 안전하게

휴대폰과 Mac 사이의 모든 것은 채팅과 승인을 포함해 종단 간 암호화됩니다. 밖에 있을 때 이를 전달하는 릴레이도 읽을 수 없습니다. 안드로이드 앱을 지문이나 얼굴로 잠글 수 있어서, 빌린 휴대폰으로 명령을 승인할 수 없습니다.

가격

에이전트, 터미널, 알림은 모든 요금제에 포함됩니다. 내 네트워크에서는 시간 제한 없이 무료이고, 다른 네트워크에서 컴퓨터에 접속하는 릴레이 시간이 하루 30분 포함됩니다. Pro(월 $2.99) 또는 평생(한 번 $24.99)이면 하루 제한이 없어집니다. 미국 가격 기준이며, Google Play에서는 현지 통화로 표시됩니다.

자주 묻는 질문

안드로이드에서 Claude Code를 쓸 수 있나요?

Claude Code는 휴대폰이 아니라 컴퓨터에서 실행됩니다. Peering을 쓰면 Mac에서 계속 실행되고, 안드로이드 앱이 채팅을 보여 주며 새 채팅 시작, 질문 답변, 명령 승인을 할 수 있습니다.

Codex와 OpenCode도 되나요?

네. Peering의 에이전트 화면은 Mac에 설치된 Claude Code, Codex, OpenCode를 지원합니다.

앱을 열지 않고 명령을 승인할 수 있나요?

네. 알림에 허용과 거부 버튼이 있습니다. 안드로이드에서는 Peering이 백그라운드에서 세션을 열어 두는 동안 도착합니다.

Peering이 내 코드나 API 키를 보나요?

아니요. 에이전트는 내 자격 증명으로 내 Mac에서 실행되고, 휴대폰과 Mac 사이의 연결은 종단 간 암호화됩니다.

Windows 버전이 있나요?

Windows 호스트는 초기 베타입니다. Claude Code 채팅은 있지만 변경 검토, 커밋, 푸시는 아직 없고, 실제 PC에서 실행해 본 적이 없습니다.
