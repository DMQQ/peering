Controle um PC com Windows pelo celular: um beta inicial

Escrito por quem faz o Peering, novembro de 2026. Leia o quadro abaixo antes de qualquer coisa.

Sem rodeios: o Peering Host para Windows está pronto e os testes dele passam, mas ele ainda não rodou em um PC com Windows de verdade. Ele não está na página de download. Se você quer testar antes e contar o que quebra, escreva para support@getpeering.app. Se você precisa de algo que funcione no Windows hoje, as páginas do Chrome Remote Desktop e do TeamViewer dizem o que usar no lugar.

O que é o host para Windows

Os mesmos apps do Peering para celular que controlam um Mac podem se parear com um PC com Windows rodando o Peering Host. Ele fica na bandeja do sistema, mostra um código de pareamento de seis dígitos na janela dele, aceita celulares pareados na sua rede e pelo relay, e mantém a chave de cada dispositivo protegida pelo Windows. O celular mostra o PC na lista dele marcado como Beta.

O que já está pronto

  • A imagem: uma tela, ou uma janela, como H.264 codificado por hardware a 15, 30 ou 60 quadros por segundo, com o ponteiro desenhado.
  • Entrada: mouse, teclado e texto, incluindo o modo trackpad e gestos com vários dedos pelo celular.
  • Som do PC, e uma área de transferência compartilhada.
  • Terminais: shells do PC no app do celular.
  • Chat do Claude Code, com aprovações e turnos concluídos enviados ao celular.
  • Arquivos: navegue pelas pastas do PC e baixe arquivos, e pastas como zip.
  • Alcance: o mesmo pareamento criptografado, a mesma descoberta na rede local e o mesmo relay do Mac.

O que ainda não está pronto

  • Fontes por aplicativo, miniaturas e o mosaico de janelas.
  • Áreas de trabalho virtuais, telas virtuais e uma cortina de privacidade.
  • Manter o PC acordado e agendamentos para acordá-lo.
  • Revisar as alterações de um agente, fazer commit e push pelo celular.
  • Assinatura de código. O Windows SmartScreen avisa na primeira vez que o host roda, porque o editor ainda não foi verificado.

Quem deveria testar agora

Alguém à vontade com um beta: que consiga rodar um instalador sem assinatura, ler um arquivo de log quando algo não aparece e nos mandar o que vê. O instalador é por usuário, não precisa de direitos de administrador e pode iniciar o host no login. O código-fonte está no repositório, se você preferir compilar por conta própria.

O lado do celular

Use o app para Android (em breve no Google Play) ou o app para iPhone. O Android esconde os controles que um host Windows não suporta. O app para iPhone por enquanto mostra alguns controles exclusivos do Mac que o host Windows ignora.

Preços

Os mesmos do Mac: grátis na sua própria rede, 30 minutos por dia de relay a partir de outras redes, e Pro ou Vitalício para uso ilimitado. O plano pertence ao celular, então vale para todos os computadores que você parear.

Perguntas

Posso controlar um PC com Windows pelo celular com o Peering?

Em um beta inicial. O host para Windows está pronto e testado no código, mas ainda não rodou em um PC de verdade. Peça acesso antecipado em support@getpeering.app.

Quais celulares podem controlar o host para Windows?

Os apps do Peering para Android, que chega em breve ao Google Play, e para iPhone e iPad.

Por que o Windows me avisa quando eu o executo?

O instalador beta ainda não tem assinatura de código, então o SmartScreen não reconhece o editor. Escolha Mais informações e depois Executar assim mesmo, se você confia na origem.

O host para Windows precisa de direitos de administrador?

Não. O instalador instala só para o usuário atual.

Ele roda o Claude Code pelo meu celular?

Sim, o host para Windows tem o chat do Claude Code com aprovações no celular, mas ainda não tem revisão de alterações, commit nem push.
