Uma alternativa ao Chrome Remote Desktop para o seu Mac

Uma comparação honesta, escrita por quem faz o Peering. As informações sobre o Chrome Remote Desktop vêm das próprias páginas de ajuda do Google, novembro de 2026.

A versão curta. O Chrome Remote Desktop é grátis, acessa Windows, Mac e Linux, e é uma boa escolha se uma conta Google não for problema para você. O Peering só cuida do seu próprio Mac (e de um beta inicial para Windows), não precisa de conta e acrescenta o que você usa em um Mac remoto: um teclado com as teclas do Mac, um terminal, arquivos e agentes de código.

Quando o Chrome Remote Desktop combina melhor

Se você precisa acessar máquinas Windows ou Linux hoje, de qualquer navegador, sem pagar nada, o Chrome Remote Desktop faz isso bem e o Peering não. Ele também é um jeito razoável de ajudar um parente com um código de acesso de uso único. Se você já vive dentro de uma conta Google, o login dele não é um custo.

Quando o Peering combina melhor

Você não quer uma conta Google no meio. Com o Peering, o seu celular e o seu Mac se pareiam com um código de seis dígitos e confiam nas chaves um do outro. Ninguém mais tem um login que chegue ao seu computador.

Você usa o Mac como Mac. Command e Option, teclas F, atalhos por app e macros ficam em uma barra acima do teclado. O modo trackpad parece o trackpad do Mac, com dois dedos para rolar e deslizar entre mesas.

Você quer mais que uma imagem. O Peering acrescenta o som do Mac, uma área de transferência que aceita imagens, um navegador de arquivos, um terminal e uma visualização de chat para o Claude Code, o Codex e o OpenCode com aprovações em uma notificação. Veja Claude Code no Android.

Você quer escolher o que vê. Mostre uma tela, um aplicativo ou uma janela, para que uma tela pequena mostre aquilo em que você está trabalhando em vez de uma mesa inteira.

Como é uma sessão no celular

Abra o Peering e o Mac pareado está no topo da lista, marcado como online. Um toque conecta. A barra da sessão mostra o nome do Mac e diz como a conexão está correndo: LAN em casa, DIRECT quando as duas pontas acharam um caminho uma até a outra pela internet, RELAY quando não acharam. Abaixo dela fica a tela do Mac e, na parte de baixo, um dock de teclas rápidas: setas, Enter, Escape, Copiar, Colar, Desfazer. Deslize o dock para ver atalhos, macros e as teclas de função.

Se a conexão enfraquece, a qualidade Automática baixa a imagem em vez de deixá-la travar, e volta a subir quando o link se estabiliza. Saia do app e o Mac pausa a imagem, para que nada que você não esteja vendo seja transmitido; volte e ela continua.

Como migrar

Você pode rodar os dois no mesmo Mac enquanto decide. Instale o Peering para Mac, permita Gravação de Tela e Acessibilidade, instale o app no celular e pareie na sua rede de casa. Na sua própria rede ele não custa nada e não tem limite de tempo, então não há período de teste para ficar de olho. Quando estiver satisfeito, remova o host do Chrome Remote Desktop dos itens de início de sessão do Mac.

Perguntas

Existe uma alternativa ao Chrome Remote Desktop sem conta Google?

Sim. O Peering não tem conta nenhuma: o celular e o Mac se pareiam com um código de seis dígitos e confiam nas chaves um do outro.

O Peering é grátis como o Chrome Remote Desktop?

Na sua própria rede, sim, sem limite de tempo. A partir de outra rede, o plano grátis inclui 30 minutos por dia; o Pro custa US$ 2,99 por mês ou o Vitalício US$ 24,99 uma vez.

O Peering controla Windows ou Linux?

Linux não. Existe um host para Windows como beta inicial, que ainda não rodou em um PC de verdade. Para frotas mistas hoje, o Chrome Remote Desktop cobre mais.

O Peering funciona pelo navegador?

Não. Ele funciona pelo app para Android, que chega em breve ao Google Play, e pelo app para iPhone e iPad.
