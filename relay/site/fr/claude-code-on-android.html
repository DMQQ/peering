Claude Code sur Android, qui tourne sur votre Mac

Rédigé par l'équipe qui fait Peering. Vérifié sur le code de l'app, novembre 2026.

En bref. Votre agent de code continue de tourner sur votre Mac, avec vos dépôts, vos clés et vos outils. Peering sur Android vous donne sa discussion sur le téléphone : en lancer une, la suivre, répondre à ses questions, relire ce qu'il a modifié, et toucher Autoriser ou Refuser dans la notification quand il demande à exécuter une commande.

Pourquoi faire tourner l'agent sur le Mac et pas sur le téléphone

Claude Code, Codex et OpenCode ont besoin d'une vraie machine : le dépôt cloné, les outils de compilation, la suite de tests, vos identifiants git. En lancer un dans une app de terminal sur téléphone, c'est tout recopier ailleurs. Peering laisse le travail là où il est déjà et fait du téléphone sa télécommande. Quand vous rangez le téléphone, l'agent continue.

Ce que vous pouvez faire depuis le téléphone

  • Lancer un agent en un toucher dans n'importe quel dossier du Mac. Claude Code, Codex et OpenCode sont pris en charge.
  • Le suivre comme une discussion, pas comme un terminal qui défile : messages, appels d'outils, sous-agents et fichiers touchés, avec des onglets quand plusieurs discussions tournent en même temps.
  • Répondre à ses questions. Quand un agent pose une question à choix, touchez une réponse. Les questions en plusieurs parties se traitent une par une.
  • Autoriser ou refuser une commande depuis la notification, sans ouvrir l'app.
  • Relire les modifications : une boîte À relire rassemble les discussions dont le travail est terminé, et chacune montre le diff fichier par fichier. Des boutons de suite apparaissent après un tour qui a modifié des fichiers.
  • Taper avec des suggestions : les commandes slash et les mentions de fichiers avec @ sont proposées pendant la saisie, et vous pouvez dicter un prompt.
  • Passer au terminal ou à l'écran quand la discussion ne suffit pas. Le shell de l'agent, un terminal simple et tout le bureau du Mac sont dans la même app.

Valider depuis le volet de notifications

Quand Claude Code veut exécuter quelque chose que vous n'avez pas autorisé, il s'arrête et attend. Sur Android, Peering publie une notification qui nomme l'agent et la commande, avec des boutons Autoriser et Refuser. Répondez depuis le volet ou l'écran de verrouillage. Même chose quand un agent termine un tour, ou quand un terminal du Mac attend un mot de passe.

Pour être précis sur les conditions : les notifications Android arrivent tant que Peering garde une session ouverte en arrière-plan. Une notification permanente nomme le Mac et propose un bouton Déconnecter, et le Mac met l'image en pause pour ne rien diffuser que vous ne voyez pas. Vous pouvez désactiver ce comportement dans les Réglages. Si Android arrête lui-même l'app, par exemple à cause de restrictions de batterie agressives, les alertes s'arrêtent jusqu'à ce que vous la rouvriez. L'app iPhone les reçoit aussi app fermée ; voir les notifications pour les agents de code.

La mise en place

Installez Peering pour Mac et l'agent que vous utilisez, comme d'habitude. Installez Peering sur le téléphone depuis Google Play dès qu'il y sera, associez une fois avec le code à six chiffres, et ouvrez l'onglet Agents. Peering trouve les agents installés sur le Mac ; il n'en fournit ni n'en paie aucun, et ne voit jamais vos clés d'API ni votre abonnement.

Assez sûr pour le laisser tourner

Tout ce qui passe entre le téléphone et le Mac est chiffré de bout en bout, discussion et validations comprises. Le relais qui le transporte quand vous êtes loin ne peut pas le lire. L'app Android peut être verrouillée par votre empreinte ou votre visage, pour qu'un téléphone prêté ne puisse pas valider une commande.

Ce que ça coûte

Les agents, le terminal et les alertes sont inclus dans toutes les formules. Gratuit sur votre propre réseau, sans limite de temps, plus 30 minutes de relais par jour pour joindre l'ordinateur depuis un autre réseau. Pro ($2.99 par mois) ou À vie ($24.99, payé une seule fois) lève la limite quotidienne. Ce sont les prix américains ; Google Play affiche les vôtres en monnaie locale.

Questions

Peut-on utiliser Claude Code sur Android ?

Claude Code tourne sur un ordinateur, pas sur un téléphone. Avec Peering, il continue de tourner sur votre Mac, et l'app Android affiche sa discussion, vous permet d'en lancer de nouvelles, de répondre à ses questions et de valider les commandes.

Est-ce que ça marche aussi avec Codex et OpenCode ?

Oui. La vue des agents de Peering prend en charge Claude Code, Codex et OpenCode installés sur le Mac.

Puis-je valider une commande sans ouvrir l'app ?

Oui. La notification a des boutons Autoriser et Refuser. Sur Android, elle arrive tant que Peering garde une session ouverte en arrière-plan.

Peering voit-il mon code ou mes clés d'API ?

Non. L'agent tourne sur votre Mac avec vos propres identifiants, et la connexion entre le téléphone et le Mac est chiffrée de bout en bout.

Existe-t-il une version Windows ?

L'hôte Windows est en bêta précoce. Il a la discussion Claude Code, mais pas encore la revue des modifications, le commit ni le push, et il n'a pas encore tourné sur un vrai PC.
