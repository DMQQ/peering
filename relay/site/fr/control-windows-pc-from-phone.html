Contrôler un PC Windows depuis son téléphone : une bêta précoce

Rédigé par l'équipe qui fait Peering, novembre 2026. Lisez l'encadré suivant avant tout le reste.

Pour être clair : Peering Host pour Windows est construit et ses tests passent, mais il n'a pas encore tourné sur un vrai PC Windows. Il n'est pas sur la page de téléchargement. Si vous voulez l'essayer en avance et nous dire ce qui casse, écrivez à support@getpeering.app. Si vous avez besoin de quelque chose qui marche sur Windows dès aujourd'hui, les pages Chrome Remote Desktop et TeamViewer indiquent quoi utiliser à la place.

Ce qu'est l'hôte Windows

Les mêmes apps Peering pour téléphone qui contrôlent un Mac peuvent s'associer à un PC Windows équipé de Peering Host. Il se loge dans la zone de notification, affiche un code d'association à six chiffres dans sa fenêtre, accepte les téléphones associés sur votre réseau et via le relais, et garde la clé de chaque appareil protégée par Windows. Le téléphone affiche le PC dans sa liste avec la mention Bêta.

Ce qui est construit

  • L'image : un écran ou une fenêtre, en H.264 encodé par le matériel à 15, 30 ou 60 images par seconde, avec le pointeur dessiné.
  • Les entrées : souris, clavier et texte, y compris le mode trackpad et les gestes à plusieurs doigts depuis le téléphone.
  • Le son du PC, et un presse-papiers partagé.
  • Les terminaux : des shells sur le PC dans l'app du téléphone.
  • La discussion Claude Code, avec les validations et les tours terminés envoyés au téléphone.
  • Les fichiers : parcourir les dossiers du PC et télécharger des fichiers, les dossiers en zip.
  • La portée : la même association chiffrée, la même découverte sur le réseau local et le même relais que pour le Mac.

Ce qui n'est pas construit

  • Les sources par application, les miniatures et la mosaïque de fenêtres.
  • Les bureaux virtuels, les écrans virtuels et le rideau de confidentialité.
  • Garder le PC éveillé et les horaires de réveil.
  • La revue des modifications d'un agent, le commit et le push depuis le téléphone.
  • La signature du code. Windows SmartScreen avertit au premier lancement de l'hôte, car l'éditeur n'est pas encore vérifié.

Qui devrait l'essayer maintenant

Quelqu'un à l'aise avec une bêta : capable de lancer un installateur non signé, de lire un fichier journal quand quelque chose n'apparaît pas, et de nous envoyer ce qu'il voit. L'installateur est par utilisateur, ne demande pas de droits administrateur et peut lancer l'hôte à l'ouverture de session. Le code source est dans le dépôt si vous préférez le compiler vous-même.

Côté téléphone

Utilisez l'app Android (bientôt sur Google Play) ou l'app iPhone. Android masque les commandes que l'hôte Windows ne prend pas en charge. L'app iPhone affiche pour l'instant quelques commandes propres au Mac, que l'hôte Windows ignore.

Les tarifs

Les mêmes que pour un Mac : gratuit sur votre propre réseau, 30 minutes de relais par jour depuis d'autres réseaux, et Pro ou À vie pour l'illimité. La formule appartient au téléphone, donc elle couvre tous les ordinateurs que vous associez.

Questions

Puis-je contrôler un PC Windows depuis mon téléphone avec Peering ?

En bêta précoce. L'hôte Windows est construit et testé dans le code, mais n'a pas encore tourné sur un vrai PC. Demandez un accès anticipé à support@getpeering.app.

Quels téléphones peuvent contrôler l'hôte Windows ?

Les apps Peering pour Android, bientôt sur Google Play, et pour iPhone et iPad.

Pourquoi Windows m'avertit-il quand je le lance ?

L'installateur de la bêta n'est pas encore signé, donc SmartScreen ne reconnaît pas l'éditeur. Choisissez Informations complémentaires, puis Exécuter quand même, si vous faites confiance à la source.

L'hôte Windows a-t-il besoin des droits administrateur ?

Non. L'installateur installe pour l'utilisateur actuel uniquement.

Peut-il faire tourner Claude Code depuis mon téléphone ?

Oui, l'hôte Windows a la discussion Claude Code avec validations sur le téléphone, mais pas encore la revue des modifications, le commit ni le push.
